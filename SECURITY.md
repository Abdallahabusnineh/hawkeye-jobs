# Security

Hawkeye Jobs runs entirely on your computer. Its window talks to a local server on 127.0.0.1 that requires a random per-launch token and refuses other hosts.

If you find a security problem — for example a way for a web page or another program to reach that local server, or for job text to run code in the window — please report it privately through **[GitHub's private vulnerability reporting](https://github.com/Abdallahabusnineh/hawkeye-jobs/security/advisories/new)** instead of a public issue. You will get a reply as soon as possible, and credit in the fix if you want it.
