## Restricted capability: runFullTrust (Submission options → Restricted capabilities)

> Hawkeye Jobs is a desktop (Win32) app packaged with MSIX, built with Python and PyInstaller. It needs runFullTrust to run as a regular desktop app: it serves its own window from a local web server on 127.0.0.1, starts Google Chrome to read public job listings on sites the user selects, and shows a notification-area icon so scheduled searches keep running after the window is closed. It collects no personal data; everything stays on the user's computer. The source code is public: https://github.com/Abdallahabusnineh/hawkeye-jobs

## Notes for certification (Submission options → Notes for certification)

> No account or sign-in is needed. On first launch, choose job titles (e.g. "Flutter Developer"), one or more countries, and the sites to search, then press Search. LinkedIn and Indeed work without Chrome; Bayt, NaukriGulf and Google Jobs need Google Chrome installed. A search takes a few minutes because the app waits between requests on purpose. The app is free, open source and has no in-app purchases or ads.
